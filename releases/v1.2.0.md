# BeatBeam DMX 1.2.0

Release promotion of the locally accepted BeatBeam Beta 1.2.0 codebase.

This release includes the native Live Show layout aligned with the iPad LIVE
console, the 24-row wall-wash rendered output, current Stage Map editing and
fixture rotation controls, and the Dynamic Composer / wall-wash choreography
and renderer-safety updates present in Beta 1.2.0.

The release uses the native Release identity and backend port. Physical DMX and
visual/show-quality acceptance remain separate from this software release.
